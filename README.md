## Conway's Game of Life

### Rules

Each iteration:

1. Live cells with <2 living neighbors die.
2. Live cells with >3 living neighbors die.
3. Dead cells with exactly 3 living neighbors are born.
4. All other cells remain the same.

### Input

- Click to toggle cells living/dead.
- Press space to iterate all cells once.
- Hold space to iterate repeatedly.
- Press R to reset all cells.
